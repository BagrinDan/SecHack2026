# MuleTrace MD — инструкции для Claude

- Единственный источник правды по порядку разработки: **`docs/DEVELOPMENT_PLAN.md`**. Читай его перед любой работой и строго придерживайся.
- Работаем коммит за коммитом в порядке плана. Не забегать вперёд и не смешивать шаги в одном коммите.
- Перед коммитом проверять DoD текущего шага; после выполнения — отмечать чекбокс `[x]` у коммита в плане.
- Сообщения коммитов — Conventional Commits, ровно как в плане.
- Фокус — бэкенд/API (`backend/`, Python + FastAPI + NetworkX). Только синтетические Zero-PII данные, никаких реальных IBAN/IDNP.
- Если задача расходится с планом — сначала обсудить с пользователем, затем обновить план.
